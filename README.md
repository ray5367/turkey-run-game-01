Turkey Trot — a turkey escape game: outrun Burt the farmer from the farmyard, through the barn, past the kitchen oven, and out the forest gate. Dodge the falling carving knives, hide behind the hay bales, grab the corn and the pie, and don't let the oven catch you.

## Run it

```sh
node serve.ts # then open http://localhost:8080
```
